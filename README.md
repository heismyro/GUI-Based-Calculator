# GUI-Based Calculator — SDLC Lab-2

This version follows the hand-drawn calculator layout supplied for the laboratory project.

## Layout

```text
┌───────────────────────────────┐
│          DISPLAY              │
├──────┬──────┬──────┬──────────┤
│  7   │  8   │  9   │    ÷     │
├──────┼──────┼──────┼──────────┤
│  4   │  5   │  6   │    ×     │
├──────┼──────┼──────┼──────────┤
│  1   │  2   │  3   │    −     │
├──────┼──────┼──────┼──────────┤
│  C   │  0   │  =   │    +     │
└──────┴──────┴──────┴──────────┘
```

- Body/background: **Black**
- Numeric buttons: **Red**
- Action/operator buttons: **Yellow**
- Display: White

## Run

Open the folder in VS Code and run:

```bash
python myGUI.py
```

No external packages are required.
